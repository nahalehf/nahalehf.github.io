# Nahaleh Fatemi — Personal Website

A minimalist, responsive, single-page research portfolio built with HTML, CSS and JavaScript. No build tools are required.

## Preview locally

Open `index.html` in your browser. Internet access is helpful for the Google Fonts, but not necessary for layout.

## Publish on GitHub Pages

1. Sign into GitHub and create a **public** repository named `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with your exact GitHub username).
2. Upload `index.html`, `styles.css`, and `script.js` to the **root** of the repository, and commit the files. You can upload `README.md` as well.
3. Under **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Open `https://YOUR-GITHUB-USERNAME.github.io` after GitHub finishes publishing. If Pages is not enabled immediately, check the Actions tab for deployment progress.

## Customize before publishing

- In `index.html`, replace `REPLACE_WITH_YOUR_EMAIL` in the email button with your real preferred email address.
- Replace the generic GitHub, LinkedIn and Google Scholar homepage links with your personal profile URLs.
- Replace the descriptive publication placeholders with verified article titles, authors, venues, dates, and links. They are **not** formal citations.
- Edit project text or education details to match your preferred wording.
- To add a CV button, copy `cv.pdf` to the repo root and add a link such as `<a href="cv.pdf">Download CV</a>` in `index.html`.
- To change colors, edit the CSS variables at the top of `styles.css`.

The website deliberately avoids claiming unverified publication acceptance or inventing social URLs or email addresses.
